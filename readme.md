# Freight Rate Prediction

Predicting the posted rate of freight loads from lane, distance, equipment, weight and date.

## Results

| Model | MAE on test (Sep–Oct) |
|---|---|
| Baseline: quote signal × distance | $195 |
| Baseline: lane median × distance | $139 |
| **Random Forest (final model)** | **$55 (2.4%)** |

The full analysis, including model comparison and limitations, is in `notebook.ipynb`.

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

```

```

## How to run

1. Open `notebook.ipynb` with the project environment and run all cells. This generates:
   - `validation_predictions.csv`
   - `data/december_chart_inputs.csv` with the `predicted_rate` column filled
2. Validate the outputs and generate the December chart:

```bash
python score.py --predictions validation_predictions.csv --december-predictions data/december_chart_inputs.csv
```

The chart is saved to `scorer_results/candidate_december.png`.

## Approach

- **Target:** rate per mile, converted back to total rate by multiplying by distance.
- **Cleaning:** fixed negative weights (sign errors), filled missing values with training medians, and removed isolated extreme rates (below 1 or above 4 $/mile).
- **Split:** time-based, January–August for training and September–October for testing, mirroring the November–December validation period.
- **Features:** lane median rate per mile (computed on training data only), equipment, distance, weight, day of week and day of month.
- **Model selection:** compared Ridge, Random Forest and LightGBM, each with all features and with December-compatible features only. Random Forest with December-compatible features performed best.
